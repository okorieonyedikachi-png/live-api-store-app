# The Daily Outlet

A modern, responsive e-commerce website built with **HTML**, **CSS**, and **JavaScript**.

## Live Demo
🔗 [View Live Website](https://okorieonyedikachi-png.github.io/live-api-store-app/)

## Features
- Product listing with category filtering
- Search functionality
- Shopping cart with quantity controls and remove option
- User authentication (Sign Up / Login)
- Order history and order tracking
- Floating draggable cart button
- Fully responsive design (mobile & desktop)

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (ES6 Modules)
- LocalStorage for cart and user data

## What I Learned
- Building interactive UI with pure JavaScript
- Managing application state with LocalStorage
- Creating responsive layouts
- Handling user authentication flow
- Working with modular JavaScript files
